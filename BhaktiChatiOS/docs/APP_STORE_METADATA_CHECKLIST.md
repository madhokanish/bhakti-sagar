# App Store Metadata Checklist

## Identity
- App Name
- Subtitle
- Bundle ID
- Primary category / secondary category
- Age rating questionnaire

## Copy
- Promotional text
- Description
- Keywords
- Support URL
- Marketing URL
- Privacy policy URL

## Visual assets
- App icon (1024x1024) in app icon set
- iPhone screenshots
- iPad screenshots (if iPad supported)
- Optional app preview videos

## Compliance
- Export compliance
- Content rights
- Sign-in compliance notes (if third-party sign-in)
- Privacy manifest / nutrition labels

## Release config
- Version and build number
- What's New text
- Phased release setting
- Internal/external tester groups

## BhaktiChat-specific sanity checks
- Screenshots cover: Home, Chat, Divine Image, Aarti, Choghadiya, Profile
- Religious/disclaimer copy is clear where needed
- AI-generated image behavior explained in description
